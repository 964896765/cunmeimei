# 搜索地区、七模板与高级筛选 · 2026-10-19

沿用冻结配色、现有18路由和五导航，在原项目直接修改。不改版本，不生成压缩包，不部署。

## 实际行为

- 顶部不再使用定位图标，显示“地区：上海市”等当前浏览地区名称。点击仍进入现有城市/区县页；从搜索页进入时，选定后返回原搜索页，首页原有选城返回首页行为保留。
- 全部分类默认项之外只有七个业务选项：招聘人才、房产资产、商品闲置、商家机构、服务供需、活动资讯、公共信息。发现频道与搜索共用 `utils/business-templates.js`，稳定编码JOB/PROPERTY/GOODS/MERCHANT/SERVICE/EVENT/PUBLIC。历史community数据与深链兼容，不将其猜测成活动或公共信息；尚未开放的模板不因此获得发布或资质权限。
- 高级筛选：地区范围；发布时间不限、近24小时/3天/7天/30天/90天；距离不限、1/3/5/10/20/50/100km。筛选面板先暂存，点“应用筛选”生效；取消保留已应用条件；重置清空面板草稿。
- GPS只在明确申请距离范围时请求；授权失败保持原条件并提示，不把失败伪装成不限距离查询。关闭面板/离页后丢弃迟到定位。浏览城市、实际GPS与发布地点仍相互独立。
- 距离仅支持核验公开位置的商家与可预约服务。其他分类的距离控件禁用；切到不兼容分类时只清除距离，保留日期，并给出说明。个人信息即使存在异常地图元数据，也不会混进距离结果。
- 当前筛选摘要显示已生效地区/时间/距离。日期与半径在PostgreSQL分页前组合过滤，可与综合、价格、最新排序同时使用，不通过只过滤客户端第一页冒充全量查询。

## 后端与数据

`/api/v1/feed`增加可选 `days`、`radiusKm` 参数；非法范围、缺失/无效坐标及不允许定位的分类返回400，不静默放宽条件。现有公开位置核验、审核、有效状态、城市与测试数据隔离继续在后端生效。半径基于已有公开坐标计算，近似位置按已公开精度计算，不提供个人地址反推。

复用现有表与查询，无新增迁移、无历史数据重写、无PostGIS等新依赖。腾讯Key不参与设备GPS半径计算；未配置Key时，逆地理解析仍保留原待验收状态。
