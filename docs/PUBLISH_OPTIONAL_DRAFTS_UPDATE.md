# 主动草稿与发布确认流程验收

> 当前入口与返回规则以 [发布与草稿箱最终规则](PUBLISH_DRAFT_FINAL_RULES.md) 为准：草稿只在发布页提供，个人中心只保留发布、收藏、预约。以下保留本轮之前的主动草稿实现记录。

日期：2026-10-20。此记录取代 `PUBLISH_FORM_FLOW_UPDATE.md` 中的自动暂存方案；旧记录仅作上一轮对照。

## 本轮实际实现

- 新建直接进入空白填写页，不读取或提示恢复已有草稿。分类路径右侧为“取消”；没有草稿状态行，也没有底部保存按钮。
- 填写页底部只有“下一步 · 预览”。标题、价格、成色、描述、实际地区按参考顺序排列，照片采用统一线性图标入口；表单继续隐藏五个 Tab。
- 输入、图片读取、预览、页面隐藏和卸载均不生成或覆盖正式草稿。
- 有未保存修改时，左上角返回打开三个明确选项。新建为“保存至草稿 / 直接放弃 / 继续填写”；草稿编辑为“保存修改 / 放弃修改 / 继续编辑”。无修改可直接返回。
- 新建取消清空本次内容并退出；草稿编辑取消仅丢弃编辑副本，原草稿及其原照片不受影响。
- 本机草稿改为按稳定 clientKey 独立保存，多份内容可并存；更新带本机修订检查，另一窗口保存的新版本不会被静默覆盖。历史单份本机草稿仍可读取，未批量删除旧数据。
- 原账号草稿继续通过现有私有 API 按 revision 更新。主动保存账号草稿失败或冲突时停留编辑，不自动转存、覆盖或宣称已保存。
- 新建的独立草稿目前保存到本机；本轮没有新增云端多草稿系统，也不把原账号单份接口包装成无限多云端草稿。保存成功的提示明确说明“本机草稿”或“账号”。
- 预览采用实际上传照片的大图轮播、价格、标题、分类路径、真实已有属性、详细描述、公开地区和当前账号昵称。没有虚构认证、联系人或示例商品数据。
- 预览只读，底部仅“返回修改 / 确认提交审核”。“确认提交审核”是本次确认操作；直接调用未确认的提交处理器仍被拒绝。成功后进入“我的发布”，保持待审核状态，清理对应草稿而保留其他独立草稿。

## 模板及权限边界

新建表单写入版本3。手机新表单显示成色，品牌、型号不再作为额外必填输入；历史版本1/2及其既有品牌型号继续保留，预览有真实值才展示。前后端同步校验版本3，图片、成色、有效金额或面议、城市及其区县/镇街仍需满足相应要求。不存在以删除断言、跳过测试或开放受限类别换取通过。

分类目录27/83/418及稳定ID未变，现有43项开放映射未扩大。招聘、资质行业、审核、原区域门禁不因这次表单变化而放宽。

旧平台开放区域仍未关联行政编码。填写页默认只展示实际城市与区县；下一步如确需额外确认旧平台准入范围，会在地区组提示选择。未猜测城市归属、默认选取任意旧范围或绕过服务端校验。

## 未验收及限制

- Android/iPhone真机键盘、原生照片选择器、系统手势、读屏和持续弱网未验收。开发者工具测试使用自动化调用实际事件处理器，不等于手指与输入法测试。
- 本机草稿没有跨设备同步；原账号草稿仍为既有单份服务。
- 未测量首屏或低端机性能，不提供速度提升比例。
- 未做生产部署；未宣称418项业务已全部接通。
