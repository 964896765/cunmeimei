# 阶段 2 界面与体验升级

日期为 2026-11-11，整改分支为 `remediation/v1-stage2-prism-glass`。

用户随后给出 VM Design System 1.0。此目录保留进入新一轮整改前的工程与测试记录，当前版本作为回滚检查点。新的视觉验收按 VM 六阶段顺序重新执行。

## 已落地

- PRISM GLASS 3.0 采用用户更新的 Pearl Sunset「珍珠霞光」配色，使用珍珠白、浅蜜桃、雾粉紫、淡紫渐变与少量淡珊瑚强调。
- Quiet Glass、Private Pearl、Warm Care、Accessible Clear 通过页面材质与阅读偏好配置。
- 27 个页面使用共享顶部导航，返回入口适配微信胶囊与安全区域。
- 五个底部导航采用同一套线性图标，消息计数与当前页面激活态使用既有状态同步。
- 发现页呈现闲置、商家、服务、活动、便民五个频道，地区与筛选控件吸顶。
- 发布页使用左右分栏，保留分类搜索、草稿箱和发布进度入口。
- 发布表单增加右上角取消入口，退出确认使用共享弹窗，继续提供保存、不保存和继续填写。
- 新增共享搜索、状态反馈、业务状态标签、上传提示、隐私提示与确认弹窗组件。
- 首页和发现页增加有时效与容量限制的公开内容缓存。缓存按账号和浏览条件区分，首页广告依照服务器当前返回展示。
- 商家和员工页面增加加载、错误反馈。员工管理按当前账号和实际角色更新操作入口。
