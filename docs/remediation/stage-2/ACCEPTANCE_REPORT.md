## 验收脚本中断与恢复

前一轮截图脚本仅将开发者工具原有存储保存在进程内。自动化连接中断后，存储恢复调用失败，原登录凭据的快照随进程退出丢失。

本轮已比对隔离库身份，清除残留临时验收账号，并根据验收前截图和城市历史恢复成都。原登录凭据无法重建，开发者工具当前以游客状态作为恢复基线，需要重新登录。

脚本现已在仓库外受限目录写入恢复文件，再修改存储。结束时验证所有存储键与 API 地址恢复，断线时重连恢复。下次运行会优先恢复中断会话。各清理步骤独立执行，恢复失败时仍关闭测试服务与数据库连接。
