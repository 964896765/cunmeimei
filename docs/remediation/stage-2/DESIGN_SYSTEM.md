# PRISM GLASS 3.0

当前默认配色依照用户本轮提供的 Pearl Sunset「珍珠霞光」参考更新。

| 元素 | 规范 |
| --- | --- |
| 珍珠白页面底色 | `#FAF8F6` |
| 浅蜜桃 | `#F8EAE5` |
| 雾粉紫 | `#F2E7EB` |
| 珍珠薰衣草 | `#E9E5EF` |
| 淡珊瑚主按钮 | `#EFCBC2`，少量用于主要操作 |
| 暖银灰分隔与占位 | `#E9E6E2` |
| 卡片 | 68% 白色玻璃表面，白色边缘高光 |
| 底部导航 | 82% 白色半透明表面，12px 背景模糊 |
| 标题 | `#302D33`，44rpx |
| 正文 | `#49434B`，30rpx |
| 辅助信息 | `#655C65`，25rpx |
| 按钮文字 | `#332D31` |
| 链接与选中图标 | 加深珊瑚 `#76524C` / `#875D55` |
| 分组标题 | 32rpx，600 字重 |
| 间距 | 8、16、24、32、48rpx |
| 圆角 | 16、24、32rpx |

颜色来自 `miniprogram/utils/palettes.js`，基础样式来自 `miniprogram/styles/prism-glass.wxss`。图标生成器使用相同的颜色与导航路径。

## 材质

| 材质 | 使用范围 | 呈现 |
| --- | --- | --- |
| Quiet Glass | 首页、发现、查询、普通业务页 | 珍珠白、浅蜜桃与淡紫渐变，白色玻璃卡片 |
| Private Pearl | 消息、资料、账号、隐私及个人管理 | 珍珠白、雾紫与更轻的阴影 |
| Warm Care | 家政、亲子母婴、养老助残项目表单 | 珍珠白、浅蜜桃和雾粉紫背景 |
| Accessible Clear | 清晰主题或大字阅读 | 明确边界、大字号、清晰触控目标 |

阅读偏好保留既有六个主题键。页面材质按访问内容确定，用户可自行选择主题、大字和减少动态效果。

## 交互

发布流程依次为选择分类、编辑、下一步预览、确认提交审核、审核后展示。退出时由用户选择保存、不保存或继续填写。取消清空当前编辑缓冲。

加载反馈使用静态骨架。减少动态效果偏好同时作用于轮播和界面过渡。导航、搜索和卡片使用白色半透明表面，正文采用墨灰层级，表单输入使用实体阅读面。

图片使用原图色彩。淡珊瑚主要承担按钮与小范围强调，文字和小图标使用加深色值保证对比。普通正文和按钮文字对比度至少 4.5∶1，图标与输入边界至少 3∶1。无障碍模式使用清晰边界和实体表面。
