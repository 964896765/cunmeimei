# 发现页参考图整改

## 页面调整

按用户最新提供的发现页参考图调整页面结构。页头使用“发现同城”，下方为玫瑰色介绍横幅及城市定位插画。七频道使用文字与下划线选中态。地区、筛选和四项快捷条件组合成白色筛选卡片。

搜索与地图入口按用户要求放在右下角，搜索在上、地图在下。页面继续使用已有的固定定位、安全区与滚动显隐规则。

内容流采用独立白色卡片，包含左侧图片、分类角标、标题、实际属性标签、摘要、价格、地区、发布时间和收藏入口。无图信息使用文字卡片，图片失败时展示说明。用户图片数量、物品成色、出租类型、户型、品牌与时间均读取实际字段。

参考图中的浏览量数字需要真实统计接口支持，当前卡片提供已有的收藏操作。地区、频道和信息数量依据实际数据。原有“全部”查询继续支持跨频道检索，选择某个频道时按实际频道筛选。

城市插画由内置imagegen生成并进入项目资源目录，大小19243字节。生成提示词与路径有单独记录。[资源记录](ASSET_SOURCES.md)
