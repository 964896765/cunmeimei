# VM Design System 1.0 阶段五

## 实施范围

阶段四完成五主页面的开发者工具视觉复核后，将 VM 公共规范推广到其余 22 页。所有页面沿用原业务入口、接口、审核条件和权限判断。

| 页面 | 本阶段调整 |
| --- | --- |
| 搜索 | 共享搜索组件，条件与结果分层，共享加载、失败和空状态，高级筛选复用 BottomSheet |
| 地图 | 结果标题与位置层级、可触达筛选选项、共享筛选弹层，保留供应方地图底图 |
| 详情 | 主信息与属性分组，去除重复属性摘要，单图隐藏轮播圆点，减少动态效果时停用切换动画 |
| 地区 | 共享即时搜索、城市列表和地区弹层，搜索结果直接反馈 |
| 预约 | 突出服务摘要、日期、时段与提交反馈，保留时段校验和重复提交保护 |
| 我的预约、我的发布 | 统一业务状态、列表密度、时间和行内操作 |
| 商家资料、服务管理、预约管理、团队管理 | 统一经营摘要、编辑表单、权限状态和管理列表，保留原管理权限 |
| 聊天 | 统一消息气泡、时间、输入栏与底部空间 |
| 分类管理 | 保留 27 行业目录，首页快捷分类上限为 7 项，选中与移除状态清晰 |
| 发布表单、行业流程 | 统一字段、必填提示、分组、操作和退出确认，原 418 类目继续使用 |
| 草稿箱 | 统一保存时间、分类和继续编辑入口 |
| 手机号验证、登录 | 统一验证表单、授权提示、禁用和提交反馈 |
| 资讯 | 统一标题、来源、时间和正文阅读宽度 |
| 权益、业务记录、法律隐私 | 统一摘要、记录、操作和长文本层级 |

全站共享 SearchBar 增加禁用操作保护，所有五处原生图片轮播接入保存的减少动态效果偏好。商家申请继续显示离线模式的“本地演示”标识。页面不加载固定营销内容填充空数据区域。

## 兼容与视觉取舍

首页展示七个可配置分类和固定更多。旧账号保存超过七个快捷分类时，只读取前七项，读取过程保留原存储。用户明确保存后才更新选择，全部 27 个行业仍可从目录访问。

地图底图继续使用地图提供方的地理配色，界面控件使用 VM 色板。截图中的图片、账号和记录均来自标明“界面验收”的隔离数据。验收图片使用中性测试图，运营图片需要后续提供实拍素材复核裁切。

## 验收证据

- 开发者工具覆盖 27 路由，各拍页首、中段和底部，连同状态共输出 98 张真实截图。
- 加拍发现排序、地图筛选及底部操作、搜索高级筛选、地区列表、加载、失败、空状态、权限、游客、退出确认和大字状态。
- 33 组原生布局检查覆盖全部页头及六个大字页面，校验顶部状态区、胶囊、页头操作和五导航中心发布的位置。
- 默认回归 467 项，453 通过，0 失败，14 个数据库项跳过。阶段六另行执行严格真实 PostgreSQL 回归。
- 项目结构 27 页及 108 页面文件完整，44 份 WXML 嵌套检查通过。
- 源码指纹、截图数量、恢复状态和运行异常均由 `visual/RESULTS.json` 记录。截图复核覆盖不同像素的页面位置与弹层。

本轮测试会话结束后核对存储和 API 地址恢复结果。前轮截图脚本断线曾丢失原登录凭据，当前恢复基线为游客，原账号需要重新登录。
