# VM Design System 1.0 阶段三

## 五个主页面

| 页面 | 本轮结构变化 |
| --- | --- |
| 首页 | 左对齐品牌导航、城市标题、共享搜索、真实图片内容主视觉、常用分类、精选信息与资讯分区 |
| 发现 | 独立频道条、吸顶筛选、内容卡片、紧凑反馈，商家 / 服务 / 文章使用相应布局，排序复用 BottomSheet |
| 发布 | 行业和项目总量、独立工具行、32∶68 双栏、明确选中标记、带数量的项目组与可填写状态 |
| 消息 | 聊天 / 通知标题层级、统一摘要行、时间与状态、图标头像、未读、共享搜索和处理展开区 |
| 我的 | 资料头部、突出真实数量的事务区、合并服务与权益入口、连续账户设置列表 |

首页主视觉使用有效广告图片或公开精选信息的实际图片。主视觉中的信息从下方精选列表排除。图片加载失败时保留文字信息。无图片与无内容时按数据状态收起对应区域。

常用分类首屏展示已保存顺序中的前七项与固定更多入口。原有完整选择仍保存在账号偏好中，通过更多入口访问全部分类。

消息页面使用真实联系申请与通知摘要。图标头像对应现有业务类型，状态与未读来自服务端。已有联系申请、接受、屏蔽、预约、商家与隐私操作继续复用原方法和接口。
