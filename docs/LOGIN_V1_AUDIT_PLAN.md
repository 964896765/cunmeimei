# 青方睐村美美 · V1.0 登录审查与实施方案

日期：2026-11-03。用户确认产品名为“青方睐村美美”，微信小程序已备案。本报告不将备案等同于正式登录、手机号接口、隐私保护指引或生产环境已经验收。

## 修改前真实状态

- 原生微信小程序24页，没有独立登录或用户协议/隐私政策页面。已有手机号验证页，登录入口分散在个人中心及受限操作。
- `miniprogram/utils/api.js`已有`wx.login`和登录单飞、401重登、账号切换检查，但受限请求直接进行认证，缺少统一的可见登录界面、取消流程及返回操作上下文。
- `backend/src/server.js`已有服务端`jscode2session`，只采用微信返回的openid关联账号；AppSecret和session_key没有返回客户端。会话令牌为随机32字节，数据库只存SHA256，7天到期。认证查询检查账号active状态，注销身份指纹防止自动恢复。
- 手机号由`getPhoneNumber`单独请求。`wechat-phone.js`在服务端取得号码、核对appid和国家码；号码加密保存、HMAC和掩码分离。换号/撤回会关闭已公开电话，已有绑定历史与逐条公开授权记录；手机号撤回缺少独立事件审计。
- 不自动读取昵称、头像或手机号。现有头像、昵称为用户主动编辑，继续保留。
- 正式环境已有禁用devLogin和部署预检。当前本机开发配置仍开启开发登录；服务端未配置正式微信AppID/AppSecret。手机号加密密钥存在，但这不代表微信手机号服务已开通。
- 当前缺运营主体和隐私联系渠道配置。`app.json`声明了定位用途，但未启用隐私检查字段；未通过微信后台核对《隐私保护指引》。已有“隐私设置”不能替代隐私政策与协议。
- 共享顶部组件已测量状态栏和右上角胶囊；新增页面复用，保留PRISM GLASS与六主题。

审计未输出或保存令牌、AppSecret、session_key、真实号码和原数据库URL。

## 验收条件

1. 游客访问首页、发现、分类、搜索及公开详情时不弹登录，不调用手机号、头像或昵称接口。
2. 收藏、发布、私信、商家和推广等受限操作进入统一登录；登录成功返回原页并在原账号范围继续，取消不提交业务、不丢输入。
3. 微信登录与手机号验证是独立步骤。仅后端权限判定或具体业务要求时请求号码；拒绝后可取消、重试或继续浏览，不提供不存在的替代验证。
4. 同一时刻多个受限请求只打开一个登录页；过期重登、账号切换、退出与迟到响应不恢复旧会话或串号。
5. 登录只通过微信code服务端交换；前端不收到AppSecret、session_key或真实他人号码，正式环境开发登录被阻断。
6. 版本化同意记录、手机号授权/换绑/撤回可审计；号码默认不公开，沿用每条信息单独公开同意与撤回。
7. 顶部胶囊、状态栏及底部安全区在六主题和大字下通过实际渲染；界面仅品牌、说明、微信按钮、游客入口与协议。
8. 原发布、收藏、私信、商家、广告、积分、注销及管理后台回归通过。
9. 微信真机实测游客、微信登录、独立手机号验证、拒绝、返回原操作、过期与注销。开发工具、隔离API和模拟微信响应单独标识，不能代替真机通过。
