# 首页行业快捷入口与同城资讯

2026-10-20，沿用冻结配色。

27个行业按照目录原顺序各自使用不同的线性图标：餐具、工作包、扳手、闲置箱、住宅、游戏手柄、购物袋、资讯版面、公交、汽车、剪刀、婴儿车、书本、滚筒、医疗心形、指南针、床、哑铃、婚戒、办公楼、宠物爪印、无障碍、纪念烛、货运车、幼苗、公共机构、金融保障。统一24px坐标网格、1.8px描边，并生成现有11种主题/页面色彩变体。生成脚本为 `scripts/build_industry_icons.js`；未引入图片生成服务、网络字体或外部图标依赖。

按用户最新确认：首页品牌轮播保持原设计，不降低样式或改动动效；不采用三页叠层卡片、拖动排序或新的账号排序接口。快捷区支持原生横向分页，每页四列两行8格。全部27行业均可添加；分类按已选顺序连续排列，第9个分类位于第二页第一格。“更多”只有一个，固定在最后一页右下角，即第8、16、24或32位，中间不足的位置保留空位。选择8项或9项时使用两页，选择全部27项时使用四页。编辑页仍一次展示27项，每项只有选中（标色、−）和未选中（＋）两种状态，不再要求先移除才能添加第八、第九项。不涉及发布、收藏或草稿数据。

首页点击行业通过原有发现Tab进入相应行业筛选，并保留浏览城市和区县。行业和七大业务频道是两个维度：行业显示为明确的已选条件，发现页现有频道仍可进一步缩小范围。统一搜索和地图入口继续携带该行业ID。返回详情/地图后保留原筛选；品牌“去发现”重新进入推荐时清除行业条件。分类读取不增加发布资格，未开放分类没有伪造内容。

首页底部仍为“同城资讯”，不请求用户发布信息流。目前源码没有独立的资讯内容、审核、列表及详情能力，因此使用“暂无最新资讯”，隐藏“更多资讯”，也不放临时跳转发现页的替代按钮。后续应建立有来源、发布日期和审核记录的资讯数据契约后，再接通资讯卡片与二级页面；本轮未抓取新闻或填入示例新闻。
