# 个人中心与资料页调整

2026-10-19。本轮按用户提供的个人资料、分组菜单及功能边界图实施，未扩展支付、积分兑换等业务。

## 实际完成

- 保留五导航、六主题、冻结配色、底栏、四项事务、商家入口及积分推广外框。
- 主界面采用圆形头像；头像整行进入“查看和编辑个人资料”。账户与偏好、其他服务采用两组独立菜单，退出登录独立展示。
- 资料面板采用居中头像、头像/昵称/简介/城市四行及底部隐私提示。沿用个人中心现有页内面板机制，没有新增路由。
- 昵称、120字简介、头像、资料城市通过本人资料 API 保存。资料城市复用城市目录，选择后返回资料面板，不写浏览城市、历史选城、发布地址或GPS。
- 头像复用现有受限图片上传、解码重编码与鉴权下载。绑定时核对图片归属，拒绝已经关联发布或服务的图片；已绑定头像不能被媒体删除接口直接删除。
- 资料 GET 只向本人提供字段和登录身份类型，不返回微信 OpenID、手机号或凭证。设置资料不会自动建立公开主页、公开地图点位。
- 账户与安全：账号编号、复制、真实登录身份；手机号绑定和自助注销明确标为未开放，不混入昵称、头像。
- 隐私与显示：原六主题、大字、减少动画、公开范围说明、真实黑名单及解除屏蔽。不混入通知开关和数据申请表。
- 通知设置：原有接收联系申请、通知摘要两个真实服务端设置；预约/审核为必要站内通知，微信订阅未开放。不在此显示消息正文。
- 个人数据：保留访问、更正、删除申请、进度、答复及撤回；不代替账号注销。通知中的数据处理入口转入此面板。
- 缓存：测量专用目录内当前账号头像文件的实际字节数，确认后只删除这些文件。未使用全量存储清除，不删除草稿、发布、收藏、浏览记录、登录或主题。其他账号的缓存不在清理范围内。
- 资料上传、设置读取/保存、数据请求和解除屏蔽加入账号及迟到响应检查；错误时显示可重试反馈。

## 代码位置

- `miniprogram/pages/me/index.{js,wxml,wxss}`：主界面、资料面板与独立设置内容。
- `miniprogram/utils/personal-profile.js`、`avatar-cache.js`：资料交互、受限缓存。
- `miniprogram/utils/privacy-settings.js`：分区读取、保存、请求及黑名单操作。
- `miniprogram/utils/api.js`：资料头像上传期间的账号切换检查。
- `miniprogram/pages/regions/index.js`：资料专用选城回传，不改变浏览上下文。
- `backend/src/profile.js`、`product-repository.js`、`server.js`：输入验证、本人持久化、图片归属、黑名单隔离。
- 新增迁移 `015_personal_profile.sql`，保留旧数据和既有迁移文件；已应用于本机开发数据库，没有生产部署或包版本升级。
- `scripts/build_me_icons.js`：沿用冻结主题色补齐通知、数据、关于及清理线性图标。
