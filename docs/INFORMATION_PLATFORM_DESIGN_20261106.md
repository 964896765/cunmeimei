# 信息交流平台页面梳理与布局规范

用户于2026年11月6日确认平台提供信息发布与交流。功能范围包括公开信息、联系申请、私信、预约意向、积分权益和站内推广。支付交易排除在产品范围外。

## 视觉与交互规则

- 沿用PRISM GLASS六主题与现有图标，通过间距、层级和表面数量改善密度。
- 浏览页面采用频道导航、轻筛选和内容列表三级结构，普通状态的行业、地区、时间与图片条件置于一条工具栏。
- 选中条件使用主题强调色，常态控件采用轻文字样式。大字模式允许合理换行，点击区域保持可用。
- 登录、联系方式授权和发布审核按原权限机制执行。
- 表单的必填信息保持可见，辅助说明、已完成核验、原内容及长历史可展开查阅。
- 预约采用联系意向和沟通记录表述，积分操作使用兑换、核销、退还和推广排期表述。

## 文件范围

共享部分包括 `app.wxss`、`components/browse-filters/`、`components/channel-tabs/`、`components/active-conditions/`。重点页面包括发现、搜索、地图、首页、发布、消息、个人中心、行业、沟通进度及权益推广。

## 验收

检查正常与大字、明亮与深色、选中与未选中状态。使用真实隔离接口检查筛选传递、发布与草稿、登录返回、消息、积分及预约意向。实际截图对照首屏层级与内容密度。

## 结果

已实施共享间距、卡片、频道选中态和轻筛选调整。发现列表采用文字与右侧缩略图排列，保留图片预览、收藏、日期、地域与价格说明。行业页的已完成核验、推广资料、原信息和长历史按需展开。沟通页突出当前主要操作，展开后可取消、调整时间和反馈，历史默认显示最近三条并保留完整记录。

原生测量中，普通字号下发现页的行业、范围、时间、图片筛选区高45px。首页无广告指引卡片高116px，正文底部位于卡片范围内。发现页紧凑内容项高度检查通过。主要按钮和筛选保持可触控区域，大字模式允许换行。

已复查首页、发现、发布、消息、个人中心及沟通页明暗主题截图。截图位于 `business-workflows/design-*.png` 与 `project-journeys/business-*.png`，内容均为明确标记的隔离测试信息。

纯客户端主回归452项，439通过，13项因未提供数据库连接跳过，0失败。数据库检查另由真实隔离PostgreSQL主回归1001项、严格数据库582项及72表备份恢复比对完成。两类证据分别记录，集合有重叠。
