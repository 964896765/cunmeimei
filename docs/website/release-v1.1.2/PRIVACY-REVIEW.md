# V1.1.2 协议与隐私差异报告

本次按 2026 年 11 月 19 日工作区源码核对官网公开说明。小程序同意的正式文本由后端返回，官网的修订不会改变小程序内的协议正文、版本或同意记录。

## 上一版文案与实际功能的差异

| 项目 | 核查结果与差异 | V1.1.2 处理 |
| --- | --- | --- |
| 微信登录和 OpenID | 用户勾选协议和隐私政策后，按需完成微信隐私授权。客户端用 wx.login 获取临时代码，后台调用 jscode2session 并以 OpenID 绑定账号。登录同时校验协议版本和文档摘要。游客可浏览公开信息 | 明确两条路径和同意顺序，去掉登录时同时取得头像、昵称、手机号的表述 |
| 手机号 | 认证页使用 getPhoneNumber。后端仅在微信凭据和手机号加密配置就绪时接受授权码，通过微信接口取号并加密保存。可撤回验证，展示号码需另行开启授权。不存在独立手机号登录 | 说明触发条件、用途、撤回和公开条件，不把微信能力认定为生产已开通 |
| 头像、昵称、简介、常驻城市 | 个人资料 API 白名单包含昵称、简介、城市编码、头像引用。头像由用户主动选择并上传，手机号走独立验证接口 | 分开说明，不再将手机号列入个人资料表单，也不承诺所有资料都可独立控制可见性 |
| 图片及相册、相机 | 普通发布、编辑、行业发布、商家服务使用选择图片接口。头像用微信选择头像能力。生产商家证照上传及线上证据接口主动拒绝 | 只写允许发起的选图场景和未开通的证照上传，不宣传后台读取相册 |
| 定位及地图 | 地区、发现、搜索、地图有主动定位调用。手动选地区可替代定位。配置腾讯位置服务后，地区反查向腾讯发送经纬度；行政区列表及展示中心查询不传用户坐标 | 分开描述微信原生能力、后端坐标用途和腾讯服务的配置前提 |
| 私信和联系 | 条件允许时先走联系申请，再在受限会话发送文本。数据库记录消息正文、发送者、时间、状态和安全处理结果。未找到消息正文的定时清理策略或按条自助删除 | 明确保存与限制，未给出未经确认的天数 |
| 浏览记录和偏好 | 信息浏览记录按账号或游客区分保存在本机，上限 30 条；登录账号可从「我的」清除当前账号本机记录。城市和搜索也有本地记忆。收藏、积分、部分偏好走服务端 | 区分本机与账号数据、清除与撤回，不宣传跨设备历史 |
| 商家资质与身份 | 商家入驻记录含主体与联络信息。证照、核验材料接口仅开发环境开放，生产分支拒绝；另有按业务配置的人工行业资质核验和证据引用 | 分别说明基本商家申请和受限资质流程，不宣传当前在线收取身份证原件、营业执照 |
| 其他主动提交的信息 | 服务端有草稿、预约请求、举报、通知、隐私请求和审核相关记录。用户可在真实入口管理草稿、预约、收藏，后台可处理举报和隐私请求 | 补充业务处理目的与结果，避免全都归入「其他信息」 |
| 第三方服务和公开范围 | 源码有微信登录、手机号接口与按配置的腾讯位置服务。普通上传图片写入项目存储，证照开发路径使用私有文件存储，未找到线上对象存储 SDK。Aliyun DataV/OSM 为已打包的离线地图资料来源 | 标明实际调用及传输字段，区分离线数据来源和运行时数据共享；生产服务商和小程序平台隐私指引待核对 |
| 设备与日志 | UI 使用微信窗口和设备信息作兼容适配，未找到将设备型号、系统版本、微信版本或网络状态作为个人资料提交的业务调用。小程序后台有请求、操作和审核需求；官网模板记录 IP、请求路径、时间、状态和浏览器标识，不纳入查询串 | 删除过宽的设备采集宣称，官网和小程序分别说明 |
| Cookie | 官网静态站无 Cookie、统计脚本、登录、定位或用户提交接口；后端管理 API 的 Cookie 属于另一个服务 | 官网说明自身行为，未对生产共享网关或第三方站点作背书 |
| 官网隐私联系 | 官网无独立请求表单或已确认的隐私邮箱。小程序「我的 → 个人数据」有登录后的访问、更正、删除、注销及后台答复流程，只覆盖小程序账户 | 联系页给出真实指引和官网状态，已有专用配置可发布经确认的邮箱。不将小程序入口说成官网受理渠道 |
| 未成年人 | 原两文均为未满 14 周岁不得自行注册或提供个人信息。登录没有年龄字段、年龄校验或监护同意流程。纪念馆出生日期字段不是登录年龄核验 | 网站稿统一既有规则。年龄、监护处理及规则落地需运营方确认，未写成系统已拦截 |
| 审核、举报与交易责任 | 代码实施信息审核、状态门禁、举报和风险处置。现有服务不提供在线支付、款项托管或结算 | 说明线下交易边界以及平台仍承担信息审核、举报处理、风险处置和法定责任 |

## 保存期限、受理及删除

- 账号会话的有效期为 7 天。有效期代表凭证失效，不能当作数据库按期物理清理的承诺。注销执行后清理原登录身份、会话、绑定手机号、部分资料、草稿、收藏与偏好，留存必要的身份指纹和审核或业务记录。
- 发布内容撤回、到期或账号注销后可终止公开展示。发布、审核和举报记录不因此同时销毁。资料和上传是否能删除受关联引用和保存依据限制。
- 私信、资质、举报、审核和后台业务档案各自有用途和访问边界。现有代码中未确认统一的到期日、定时物理删除任务及备份销毁策略。运营需分别确认依据、期限或终止事件、删除办法和例外。
- 官网日志模板有独立日志文件和字段设置。仓库无已生效的生产轮转、备份保留或删除配置，不能承诺固定天数。发布前核实生产配置与公开说明是否一致。
- 官网受理待落实。需要确认公开接收渠道、负责人员、请求范围、最少必要的身份核验方式、答复期限、拒绝理由及升级处理。小程序请求由已登录账号提交，在小程序查看处理状态或答复，收到答复不代表已执行底层删除。
- 最终审阅应核对保存期限、未成年人个人信息处理和权利请求机制。若将来开放不满十四周岁用户的个人信息处理，应先核实监护人同意和专门规则的要求。[工信部公开的《个人信息保护法》全文](https://www.miit.gov.cn/zwgk/zcwj/flfg/art/2022/art_04a0f1fb5df244e39688fd5372623a8d.html)
