## 本地交付与验收

- 七个页面和原品牌风格、八份图片资源均保留。移除缺失的电话、邮箱、地址字段，联系页只保留明确状态和现有小程序帮助指引。官网说明卡与帮助不显示虚假小程序码或可扫码的措辞。
- 手机端条款页按「官方网站」「微信小程序」标注适用范围。两处跳转、折叠目录和条款锚点都可操作，小程序条款正文仍可阅读。
- 14 项自动化测试通过，覆盖七页直达、导航和资源、条款、小程序入口、联系字段和备案链接。Edge 五种宽度共 35 个页面样本和 10 项交互通过。iOS 与 Android 微信使用 UA 模拟，真机微信留待上线后验收。
- 隔离 Nginx 通过配置语法、HTTPS、七页、重定向、资源、404 和安全头检查。独立访问日志记录实际访问路径和状态，排除查询串，独立错误日志文件已创建。隔离环境同机 API 虚拟主机在重载前后保持原响应，首装撤销也已演练。
- 部署、验收及回滚的 7 段 Bash 命令已通过语法检查，生产执行结果尚无。本轮未改动小程序、后端 API 或生产服务器。
