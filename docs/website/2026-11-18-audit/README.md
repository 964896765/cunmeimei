2026-11-18 本机查询结果：根域及 API 的 A/AAAA/CNAME 返回 `ENODATA`，www 与 admin 返回 `ENOTFOUND`；四域名的直接 HTTP/HTTPS 请求均因解析失败未建立连接。详见带 UTC 时间的 endpoints.json。本机 DNS 观察不能代替权威 DNS 控制台核查或各地网络可达性测试。

因此本轮无法实测线上 HTTPS、证书有效期、www 跳转、实际页面和 API 可用性，不宣称这些项目通过。

历史文档记录的服务器为 `8.156.72.144`、Ubuntu 22.04.5、2 核/2GB/40GB，均来自此前提供的信息，**本轮未现场验证**。本机存在 SSH 客户端，但没有找到与该目标明确对应的 SSH 别名；未尝试其他机器、猜测账号或使用不相关密钥登录。

部署目录、现有 Nginx 站点、SSL 证书、CPU/内存/磁盘余量、防火墙及 API 真实监听地址仍待目标服务器只读审计。官网本地开发不依赖这些信息，生产配置必须在核实后填入。

本地原 API 使用实际支持的 GET 方法检查 health/ready，两者均返回200，结果保存在 endpoints.json。初次尝试 HEAD 返回404，经源码确认仅有 GET 路由后已更正检查方法；这不是 API 故障。该本地基线不能证明生产 API 正常。

## 文案与真实业务边界

- 官网只提供品牌和帮助信息，不提供账号、用户信息发布、消息、预约、支付或后台。
- 小程序微信登录已实现；独立手机号登录暂缓。隐私政策不能把手机号登录写成已开放功能。
- 发布页实际提供搜索、折叠菜单中的草稿箱/发布进度/发布须知/常见问题；已有表单预览与提交审核。帮助按真实入口编写，不泛化成所有分类均可无条件发布。
- 我的 → 服务中心有商家入驻与管理。生产材料提交仍受保护条件限制，官网应说明开放条件与审核要求，不承诺当前已全面开放。
- 我的 → 个人数据提供访问、更正、删除及注销申请；注销需要审核执行，不承诺即时删除全部历史证据。
- 当前“帮助与反馈”主要提供安全、通知和个人数据导向，未发现通用产品反馈工单闭环。官网不虚构在线客服或网页反馈表单。
- “邻里生活”介绍审核的实用本地信息；公开论坛发布、点赞和评论回复已关闭，不能宣传为已开放的邻里社交社区。
- 微信订阅提醒未接通，不写成已提供；站内通知与具体业务状态分开说明。
- 悼念功能默认关闭公开入口，不纳入官网已开放六类业务的承诺。
