# 青方睐村美美官网 V1.3.3

首页加入交织的蓝紫光带、沿光丝移动的粒子和蝴蝶周围的环绕光点。四翼开合与漂浮同步播放，暂停按钮一并控制首屏和导航流光。系统启用「减少动态效果」时显示静态主视觉。切换到其他标签或滚过首屏时，粒子画布暂停更新。

隐私政策按运营方确认的开放状态更新短信验证条款。第五小节和第三方服务条款均说明阿里云的投递用途。保留六位验证码、五分钟有效期、校验后立即失效和频率限制的说明。微信快捷登录、微信手机号授权和短信验证仍分别说明。

16 项 HTTP 测试通过。Edge 检查七页共 49 个页面样本和 22 项交互，覆盖粒子播放、暂停、恢复及减少动态效果。隔离 Nginx 验证七条页面路由和八项资源。本次验收覆盖官网，短信实发未在本次测试范围内。

从旧版部署时，官网 Nginx 的静态资源允许列表需同步加入 `/hero-motion.js`。部署包已包含更新后的站点配置示例。
