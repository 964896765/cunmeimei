# 青方睐村美美官网 V1.3.2 修改清单与验收

本版基于 V1.3.1，延续 QFL PRISM NEON 2.0。保留七个页面、六大服务、原版小程序码、导航和法务正文结构。

## 修改清单

| 范围 | 修改内容 |
| --- | --- |
| 首页 | 按参考图呈现蓝紫晶体蝴蝶，完整显示四片翅膀。增加蝶翼开合、背景光带和导航顶部流光。暂停控件同时控制主视觉与导航动效，并支持系统的减少动态效果设置。 |
| 隐私政策 | 分别说明微信快捷登录、微信手机号授权和待开放的阿里云短信验证。增加对应条款与个人信息请求的直达入口，说明号码用途、验证后绑定、默认不公开、撤回方式和验证码规则。 |
| 联系我们 | 为小程序个人信息请求增加官方邮箱入口 `chenjun@qingfanglai.cn`。 |
| 静态构建 | 纳入两张本地 WebP 主视觉资源。网站、Nginx 及浏览器验收覆盖新资源和动效。 |

## 构建与核验

| 检查 | 结果 |
| --- | --- |
| 静态构建 | 七个正式页面、独立 404、站点索引及本地资源构建成功。 |
| HTTP 自动化 | 16 项通过，包括导航、直达与刷新、资源、隐私说明和官方邮箱。 |
| Edge | 七页在 320、375、390、430、768、1024、1440px 下共验收 49 个页面样本，通过 21 项交互检查。页面错误和外部资源请求均为零。 |
| Nginx | 隔离容器验证七个正式路由、跳转、404、资源、安全响应头和日志处理。隔离测试中的现有 API 虚拟主机响应保持一致，回滚检查通过。 |
