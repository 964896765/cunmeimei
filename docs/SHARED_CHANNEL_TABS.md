# 发现与地图：统一八频道

2026-10-20，替代此前地图保留搜索条、七频道和默认收起的布局约定。

两个页面注册同一个 `components/channel-tabs`，数据来自已有七大业务模板注册表，顺序固定为：推荐、招聘、房产、闲置、商家、服务、活动、便民。按最终参考图收敛：组件统一为38px高、19px圆角、12px水平内边距、16px同色系线性图标、5px图文间距、8px分类间距、14px/500字号，文字色为#424A55。两页均在透明导航下10px开始、内容左右留16px，支持单行横滑且无分页点。普通项使用无描边白色胶囊，选中项使用淡青底和细青色描边；深色模式单独保证对比度，大字模式在两页同步增至16px。

发现页保留信息流，条件栏上下留白收至14px，城市入口可切换浏览地区。浅色默认主题顶部粉青氛围渐变减轻，并向页面底色渐隐；空状态采用轻白底24px圆角、24px内边距、17px标题、13px说明、36px高的小尺寸无描边按钮，文案为“查看推荐信息”。行业快捷筛选、现有排序及发布权限继续保留。

两页使用现有page-header的透明模式承载标题和安全区，消除原生导航底色与内容间的硬切割。地图标题为“地图”，底图延伸至整个页面，Tab悬浮在地图上，无独立白色矩形底板。导航及分类区域只使用轻薄的透明渐隐保障可读性，减弱地图文字与胶囊的重叠，不用整块底色遮住地图。删除搜索条和旧顶部容器。默认半展开，可拖动收起/半屏/展开；展开时也保留统一Tab。底部面板固定头部只放“当前区域信息”、数量和唯一的“筛选”按钮，下一行以只读文字显示当前城市、地图范围和实际排序。卡片列表单独滚动，不再并排放四个下拉入口。

城市、地图范围、发布时间、排序、图片、发布者条件集中在独立筛选抽屉，底部为“重置 / 查看结果”。范围与其他筛选条件在点击“查看结果”后应用；关闭抽屉不应用未确认条件，重置只重置当前编辑内容。城市入口复用现有地区选择页，选城后返回地图立即重新定位并查询。空结果仅显示“当前区域暂无公开信息 / 移动地图或切换分类试试”。

地图右侧仅两个按钮：回到浏览城市中心、展开结果。回中心不调用GPS，也不更改浏览城市；距离文案为“距视野中心约…”，只依据已公开坐标计算，不能被解释为距用户当前位置。发布时间仅在真实数据提供时展示。范围控制使用实际地图视野，城市视野会重置地图中心并重新查询。地图移动后仍由用户点击“搜索此区域”更新；筛选与分类变更沿用同一公开点位API。

增加招聘Tab仅统一页面结构，没有开放招聘或其他尚未接通的地图业务。现有后端仍仅提供核验通过的商家与服务公开点位，不生成示例点位或个人住宅坐标。地图仍继承发现的业务类型、关键词、行业与适用排序。未改动首页品牌、快捷分页或配色。
