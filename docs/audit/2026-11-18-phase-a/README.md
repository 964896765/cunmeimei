## 已确认的优先问题

1. **后台超级管理员操作按钮消失**：`backend/admin/workflows.js:14` 的严格角色相等判断与 `canRole` 权限继承冲突。用实际源码执行只读 VM 渲染，运营可见 2 个权益处理按钮、3 个行业审核按钮，核验员可见 3 个资质按钮，超级管理员在这些记录中均为 0。见 [复现结果](admin-render-reproduction.json)。这属于界面阻断，不是绕过服务端权限。
2. **商家正式入驻链未开放**：`backend/src/server.js:291` 在正式环境拒绝商家证据提交，证照上传也明确阻止。开发环境上传成功不能作为生产入驻闭环证据。需安全验收后开放受控私有材料流，或先做完整可追踪的人工核验替代；不能直接删除保护条件。
3. **管理员身份与最小权限不足**：已有三个角色密码、会话过期、CSRF、限流、服务端权限白名单和操作审计；但缺个人管理员账号、账号停用/凭证轮换流程、五类岗位的细粒度授权。审计能关联角色与会话，尚不能可靠归属具体工作人员。
4. **发布体验未统一**：居民表单已有预览与离开保存提示；行业表单只有确认提交，没有内容预览步骤。两条主要表单未接入自动保存，进程终止后未手动保存的修改可能丢失。
5. **数据规模增长后的可达性缺口**：聊天前端未接入后端历史分页，仅显示最近 50 条；我的发布/预约及部分后台用户、资质、风险、审计列表固定 100 条，没有完整翻页。不能声称任意规模数据都可操作。
6. **上线环境与能力仍未验证**：本地缺真实微信凭证、地图服务配置、真实运营联系信息和正式材料存储；当前 DNS 查询未得到 API/admin 可用地址。没有进行生产 SSH、TLS、备份恢复或双端真机验收。

全部问题、来源、优先级及验收要求见 [风险表](risks.md)。未证明存在生产越权漏洞；也不能以源码检查或依赖扫描替代安全验收。

## 入口增加、合并与保留建议

保持五大底部导航、七频道、搜索/地图右下角入口、发布搜索末尾折叠菜单、独立积分及服务中心卡片。

| 入口 | 建议 | 原因 |
| --- | --- | --- |
| 我的发布 / 行业“我的业务” | 先增加统一记录索引与正确分流，保留原表单与工作台 | 40 与 375 项使用不同业务路径，普通用户不应猜记录存放位置 |
| 草稿箱 | 聚合居民本机/账号草稿与行业草稿，标记来源 | 目前草稿来源分散，避免只看到一部分 |
| 审核进度 | 从发布记录直接看原因、材料补充与重新提交；通知跳回原记录 | 不再新增一个重复的“审核中心”顶级入口 |
| 帮助与反馈 | 在已有帮助页补真实反馈工单、进度及答复 | 当前主要是安全说明和导向，未发现普通产品反馈提交闭环 |
| 我的举报 | 在原服务中心保留汇总入口，区分普通、行业、悼念举报 | 原端点与权限保留，避免只汇总行业举报 |
| 业务进度 / 我的预约 | 保留，按来源跳转并标明双方角色 | 预约时段与双方履约记录含义不同，不能简单删除其一 |
| 商家入驻 / 服务中心商家管理 | 保留首页引导与已有管理入口，复用同一状态判断 | 场景不同；无需再新增第三个商家中心 |
| 手机号状态 | 账号与安全为完整管理入口，服务中心可保留状态摘要跳转 | 统一目的地，减少重复页面和歧义 |
| 积分中心 / 权益兑换 | 保留中心与上下文兑换入口，统一账本和非现金说明 | 已确认保留非现金权益，不扩展支付与打赏 |
| 微信订阅提醒 | 正式配置后再开放授权；站内通知继续可用 | 当前显示“未开放”是实情，不能做无效授权按钮 |
| 悼念专区 | 保持独立、默认关闭公开入口 | 不并入第 28 行业；与殡葬信息查询严格分开 |

这些是建议，阶段 A 没有实际移动或删除任何入口。统一索引需验证权限、分页和计数，不通过前端拼接无限量列表解决。

## 搜索、筛选、加载与返回的判断

源码扫描覆盖全部注册页面与 include 模板：未发现静态事件绑定缺失或确定的字面量目标路由不存在，JS AST 解析无错误。动态商家服务/预约/团队路由经模板值核对，三个目标均已注册。完整清单见 [页面与绑定](pages-and-bindings.json)、[导航和 API 调用位置](navigation-and-api.json)。这些不证明登录回调、深链接、返回栈、键盘、网络异常全部通过。

已实现统一页面尺寸计算、顶部测量、底部安全区、固定导航；发布两栏独立滚动，发现筛选按频道生成并同步请求；消息会话/通知保留各自滚动位置。之前开发者工具的吸顶及收藏分页结果可以复用，但需在后续修改后重新回归。

发现七频道导航支持点击及导航条横向滚动，未发现内容区横滑换频道与逐频道列表/筛选/滚动快照。此处属于新任务体验差距。当前切换会清除部分条件并处理不适用距离条件，不应为了“记忆筛选”恢复不适用字段。

公开 feed 有地区/分类/行业字段过滤、稳定的同值 ID 排序、前置过滤后分页、客户端去重、过期/下架/行业核验过滤。当前核心文本搜索使用转义后的 `ILIKE`；分类目录有 aliases，但未发现已接入信息搜索的完整同义词、常见错别字纠正。距离排序只用于具有已核验公开位置的内容，有提示，不应虚构普通房源或私人位置。

缓存有 10 分钟有效期、四条容量限制、到期过滤；列表缓存可能在离线时保留服务器已下架的文字摘要。详情/媒体仍由服务端校验。需补“缓存内容、以联网核对为准”的明确反馈及重验，不能保证离线瞬时撤回。
