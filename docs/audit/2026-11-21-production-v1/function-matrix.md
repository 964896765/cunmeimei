# 小程序页面及业务完成度

“本地已验证”覆盖本轮列出的源码编译、HTTP、PostgreSQL 或浏览器项目。“已实现／待联调”表示已有该路径，所列外部能力、真实数据或真机仍待核验。前端帮助展示、缺失接口和受控关闭分别在对应条目标出，安全风险见风险表。所有主包路由均为 `pages/<目录>/index`，表中的目录与源码一致。
