# 个人中心布局调整 · 2026-10-18

按用户参考图调整现有个人中心，配色、六主题及偏好、底部导航和现有业务权限保留。随后按补充要求，为“积分与推广”增加与商家中心一致的圆角外框。

## 实施内容

- 顶部改为线性个人图标、真实展示名称、“个人资料与账号管理”和右侧箭头。
- “我的事务”采用一排四项：我的发布、草稿箱、我的收藏、我的预约。发布、收藏、预约数量取真实后端；未登录或尚未取得数据时显示横线，不填造数字。草稿保留入口，不伪造总数。
- 积分与推广、商家中心分别使用圆角边框；前者保留“规划中”，点击仅作未上线说明；后者继续进入真实商家入驻／工作台，不赋予任何额外权限。
- 下方为浏览记录、隐私与显示、账号与设置、帮助与申诉四行入口。
- 个人资料、修改名称、复制授权账号标识、消息入口、退出登录收在原路由的账号面板中。隐私、主题、大字、减少动态、通知摘要、联系限制及个人数据请求继续使用原有实现。
- 帮助提供既有安全说明、举报入口指引和数据请求入口；独立申诉通道明确标为尚未开放。本次没有增加申诉、积分等业务模块。
- 增加摘要失败重试与原有数量保留；拒绝旧账号、已卸载页面的迟到摘要及收藏结果，防止重新组织账号入口后出现串号显示。
- 大字模式下推广卡自动增高，规划标签可换行，右侧箭头保持在文案右侧。

- `miniprogram/pages/me/index.wxml`、`index.wxss`、`index.js`。

后端接口、数据库和历史迁移没有修改。`me-layout-baseline.json` 记录并校验冻结色源、色彩合同、全局样式、主题运行代码、app 配置和底栏源码均未变化。
