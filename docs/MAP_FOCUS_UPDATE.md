# 地图主体布局与选城居中修复 · 2026-10-19

沿用冻结配色和现有18路由/五导航，不新增业务模块，不生成ZIP、不改版本，不生产部署。

## 实际修改

- 原生标题由“地图找信息”简化为“地图”。全屏原生map继续承载地图，不重复显示五导航。
- 顶部只留48px搜索框及单行地区/分类。默认分类为全部、商家、服务；招聘、房产、闲置、活动、便民收进更多。那些分类目前没有已接通地图点位，不因此开放资质或个人地址。
- 地区只保留一个入口；选定城市/区县后返回地图并更新浏览范围。同城重新选择也会重新居中；取消选择保留原视野。
- 一个46px线性定位按钮；“搜索此区域”只在用户移动/缩放/GPS改变视野后出现，查询成功后隐藏。取消常驻刷新及第二个选城按钮。
- 默认折叠面板实测128px（含底部安全区域），只显示附近信息、数量和两行简洁空状态。不再用大白卡、列表找信息按钮或三档切换按钮。
- 有结果时拖动手柄在折叠、半屏与展开间转换；手柄也支持点击/读屏操作，空结果保持紧凑。单条信息的半屏高度适当缩小；选点直接选中对应卡片，详情仍由明确按钮打开。
- 保留按缩放聚合、点位/列表联动、分页、错误重试、迟到请求丢弃及定时器清理。账号/测试模式变化清空旧点位；手指取消不会意外改变面板档位。
- 地图搜索跳转原有统一搜索页，增加只读的公开位置范围标识。后台 `publicOnly=1` 在分页前限制为已核验的公开商家/可预约服务；不把普通个人发布作为地图结果，也不制作第二套搜索页面。

## 原城市错位的原因和修复

原地图初始值是全国视野，经由 `/geo/center` 调用腾讯城市目录后才更新位置。缺Key时保留全国中心，只更新城市文字，因此出现上海标题与北方地图不匹配。

现有369个浏览城市已接入静态行政展示中心，先立即设置地图位置再读取实际地图范围查询。城市切换时，未得到包含目标城市且合理缩放的原生视野前不查询旧范围。原生SDK实际返回：上海中心约31.231706/121.472644；切到东莞后实际视野也随之更新，见 `map-focus-ui-result.json` 的samples。

来源：DataV公开行政展示数据，补充的白杨/新星行政中心来自OpenStreetMap/Nominatim。JSON保留数据来源、原始输入SHA256和用途说明，生成脚本为 `scripts/build_city_centers.py`。OpenStreetMap署名与许可链接已保留：OpenStreetMap contributors，https://www.openstreetmap.org/copyright（ODbL）。

这些是近似城市展示中心，不是GPS、不代表经核验经营地址，不用于精确距离计算，也不会生成用户或商家标记。包含369/369个现有目录城市，没有用邻市或省会中心凑数。JS运行数据25349字节，JSON来源记录25272字节；无行政边界多边形、无新增地理依赖。尚未测量首屏耗时或帧率，不编造性能提升比例。

实际编译曾发现小程序不能直接require新增JSON数据模块，已按工程现有数据方式生成JS模块；控制器测试同时校验JS和来源JSON一致。最终截图/运行结果均取自修复之后。

腾讯Key仍用于GPS逆解析和附近城市，未配置Key的这两项仍不声称通过。城市初始展示中心已不依赖该Key；实际GPS权限/硬件定位另待真机验收。
