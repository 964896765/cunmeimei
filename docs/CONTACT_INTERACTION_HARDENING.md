# 详情、联系、留言与聊天补强

日期：2026-11-02。本轮仅修改小程序前端、测试、验证脚本和说明；未连接云服务器、执行迁移、修改后端业务实现或生产配置。没有向真实用户发送申请、举报或聊天消息，也没有拨打真实电话。

## 本轮行为变化

- **留言**：提交绑定账号、信息、正文与回复对象。提交期间新写的内容不会被旧成功响应清空；同一内容失败重试复用原提交编号，正文或回复对象改变后使用新编号。失败提示与审核提交结果单独显示，不把待审核留言伪装成已公开。
- **交流列表**：分页失败保留已有留言，重试仍读取失败页；旧分页不能覆盖更新的第一页。点赞加在途锁，删除留言的确认会重新检查归属与页面状态。
- **联系和举报**：确认框绑定原账号与目标，防重复打开和提交。失败时保留申请/举报描述，重试回填；联系和举报失败提示会滚动到可见位置，尊重减少动画设置。旧账号或已卸载页面的回调不能继续操作。
- **电话**：授权读取加在途锁；离开页面后到达的电话响应不触发拨号。电话权限仍由服务端决定，没有更改授权、撤销或实名规则。
- **聊天**：发送期间可以继续写下一条；旧发送结果不清空新输入。同内容重试保持原编号；新内容使用新编号。发送成功后强制获取更新的消息列表，旧的轮询结果不能覆盖它。同账号正常登录续期不会清空后续输入。
- **聊天权限**：读取失败时保留草稿并暂停发送；明确会话无权访问时移除已显示的私有记录。服务端明确拒绝发送后，也先暂停发送，待权限刷新，不连续重复请求。
- **收到的联系**：同意、拒绝、撤回与屏蔽共用操作锁；确认时重新检查最新状态及方向。回复失败保留问候，供同一申请重试；确认框说明不会作为问候正文提交。
- **浏览历史**：本机浏览记录保存失败，不再把可正常读取的详情误显示为“信息不可查看”。

保留的输入是本页面内的未提交内容；本轮没有新增聊天草稿跨设备或重启持久化。账号变化会清理该页旧账号的私有状态。后端审核、手机号/资质门槛、频率限制及举报处理规则均沿用现有实现。

## 工具会话恢复说明

一次开发工具重新编译中断了验证脚本，旧清理逻辑在测试钩子消失时未能继续恢复存储。已修正为：即使钩子恢复失败也独立逐项恢复存储，并保护部分安装失败的清理路径。后续验证完成后又单独核查、移除本轮专用临时身份及其两个缓存键，没有使用clearStorage或清空用户草稿/偏好。

**原开发工具登录及验收模式的恢复未能确认，当前已回到未登录状态；后续联调需重新登录并核对验收模式。** 此问题及处理记录见[工具恢复记录](local-ui-audit/contact-tool-recovery.json)。不能把最终“无测试残留”写成“原登录完全恢复”。
