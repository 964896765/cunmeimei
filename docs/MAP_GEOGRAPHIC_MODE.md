# 地图作为发现页的地理浏览模式

布局已被后续的 [发现与地图统一八频道方案](SHARED_CHANNEL_TABS.md) 更新：地图移除搜索条、使用同一八频道组件并默认半展开。以下保留此前数据与隐私实现记录。

2026-10-20。本轮修改现有地图页、发现入口、统一搜索和公开点位查询，不增加新的业务系统或演示点位。

- 发现页继续保留主要信息流。地图入口携带当前分类、关键词及适用的排序；原发现页面保留在页面栈中。
- 地图顶部为原生返回/标题、整框进入统一搜索的搜索框、七个可横滑分类：推荐、商家、服务、房产、闲置、活动、便民。删除定位、“更多”和顶部筛选入口。
- 推荐检索当前城市与视野内所有符合公开地图条件的信息；关键词相关性、区域中心接近程度、时效和内容完整程度只影响排序，不作为人工精选白名单。
- 底部默认收起，可通过手柄点击或纵向拖动切换半屏、展开。标题、数量和唯一筛选按钮固定在列表外；展开时隐藏分类栏，保留搜索。列表仅显示小图/图标、标题、地区和公开位置精度。
- 点击普通标记高亮并定位对应卡片；聚合标记放大后拆分，最高缩放级别重合的点仍可查看列表。卡片点击直接进入原详情页。
- 拖动地图不自动发起新查询；显示“搜索此区域”，主动点击才更新地图与列表。切换分类、应用筛选、切换城市及统一搜索返回的适用条件会更新结果。
- 唯一筛选抽屉提供近7天/近30天、推荐/最新、是否有公开图片、已核验发布者。关闭抽屉不应用；重置只更改待选条件，点击查看结果才生效。筛选在服务端分页前执行，数量为完整匹配总数，点位和卡片使用同一批已加载结果。
- 已核验发布者目前依据有效商家主体记录，不将手机号验证或有公开坐标冒充身份核验。私有图片不作为地图缩略图。

地图沿用已公开内容和经后台核验的公开点位记录，不读取绑定手机号、认证材料或用户GPS生成点位，也不因进入地图请求GPS权限。手动选城从统一搜索页或未选城时的提示进入。

当前真实后端只开放商家、可预约服务的地图点位。房产、闲置、活动、便民虽有分类入口，未开放地图写入，暂无点位时如实显示空结果。房产出租方式、跨区域服务范围等专属条件尚无可用地图数据契约，本轮不添加无效筛选项。没有扩大418项目的发布权限。

验证记录：

- `map-mode-postgres.log`：隔离PostgreSQL 55项、主套件253项、端到端15项、权限9项、商家申请4项通过。覆盖筛选先于分页、总数、公开图片、商家核验、城市与测试数据隔离，隔离容器与卷已清理。
- `map-mode-unit.log`：地图/地理与页面生命周期36项通过；完整主套件也包含这些检查。
- `map-mode-ui.log` / `map-focus-ui-result.json`：微信模拟器、原生地图与真实本机API的19项检查通过。截图为实际空结果，不使用虚构房源或商家。
- `map-mode-preview-info.json`：微信开发预览上传成功，包体1,281,577字节（约1.22 MiB），低于2 MiB；未进行生产发布。
- 真机手势、设备适配与持续弱网测试未在本轮验收。
