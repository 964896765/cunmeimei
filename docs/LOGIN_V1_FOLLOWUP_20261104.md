# 登录与业务页面衔接复查 · 2026-11-04

沿用青方睐村美美现有登录、权限检查及业务流程。真机、运营主体、隐私邮箱和实际HTTPS配置按用户安排延后。本轮检查客户端已过期、取消登录、账号切换及页面关闭时的行为，不把开发者工具夹具当成真实微信授权。

## 复现的问题与修改文件

| 文件 | 问题与处理 | 验收条件 |
| --- | --- | --- |
| `miniprogram/pages/drafts/index.js`、`index.wxml` | 旧账号本机草稿原本先读后判断登录；改为过期时先登录，拒绝后显示重试入口，返回时不反复弹登录 | 未认证不读取旧账号草稿；拒绝不删草稿；同账号恢复后可继续 |
| `miniprogram/pages/commerce/index.js`、`index.wxml` | 取消重登时余额及核销记录可能仍显示；新增会话访问状态，清除列表并隐藏私有表单，保留同账号尚未提交的输入 | 过期后旧余额、核销凭据及推广记录不显示；原输入在认证恢复后继续使用 |
| `miniprogram/pages/industry/index.js`、`index.wxml` | 旧申请列表及账号表单可能在取消登录后保留可见；隐藏账号内容并清除私有列表；公开详情和新游客表单继续允许浏览 | 取消不再弹登录；旧申请不可见；同账号表单不丢；公开详情仍可读取 |
| `miniprogram/utils/workflow-client.js` | 登录等待后没有检查页面是否已关闭；未过期账号快照也可被读取；旧确认框可能跨账号继续；手机号拒绝后留下“待核对”阻塞 | 页面关闭不提交；过期不读/清除旧请求；换号后的旧确认失效；明确拒绝不冒充未知结果；真正网络未知结果继续可恢复 |
| `miniprogram/utils/auth-intent.js`、`pages/login/index.js` | 返回导航失败没有反馈给登录页；换账号返回还会保留旧页面状态 | 导航错误可见并允许本人重试；原写入不会重放；换账号返回刷新原页面，清除旧私人输入 |

不增加后台接口、数据表或迁移，不改积分价格、资格、核销、广告及商家权限。数据库迁移仍为029；生产未操作。
