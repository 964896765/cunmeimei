## 第三方与安全边界

- 已有服务端外部接口仅发现微信 `sns/jscode2session`、`cgi-bin/token`、`wxa/business/getuserphonenumber`，以及腾讯地图 `ws/geocoder/v1`、`ws/district/v1/list`。腾讯地图Key为可选增强；本地城市目录及手动选择可独立工作。wx地图/定位另需真机权限测试。
