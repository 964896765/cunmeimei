# 统一搜索与发布分类页验收

2026-10-21。此记录替代搜索前常驻筛选、本地精选，以及发布目录同时展开全部分组的旧设计。

统一搜索沿用 `/pages/search/index`，首页和发现均调用原有统一入口。采用同一套二级页面标题与返回组件，不新增底部 Tab。

- 搜索前只有输入框、最近搜索与真实热门搜索；无筛选栏，无本地精选，也不请求默认信息流。
- 提交非空关键词后显示结果与一行筛选：城市、分类、排序、高级筛选图标。
- 导航、搜索和筛选处于固定区域，结果使用独立 scroll-view；每次提交或应用筛选均回到列表顶部。
- 输入中的文字与已提交关键词独立管理。筛选和重置保留已提交关键词；清空关键词返回搜索前状态。新输入会使旧请求失效。
- 高级筛选只有时间、图片条件，以及商家/服务适用的授权定位距离条件；不重复城市、分类或排序。关闭不应用未确认条件。
- 图片条件经服务端校验，并在数据库分页之前筛选实际图片记录；未审核内容仍不可公开。复用 feed 接口与原有发布权限，没有第二套搜索接口。
- 加载、有结果、空结果、网络失败分别呈现。追加页失败保留已经显示的结果，重试原失败页。
- 页面使用白底及浅灰分隔线；深色模式保持可读的深色底。未修改首页品牌区域。

发布分类页沿用原有 27 类、83 组、418 项稳定 ID，不替换业务数据。

- 左右双栏保留，左栏宽度 31%，浅灰底，选中项白底、深色文字与 3px 竖线。
- 左侧字号 14px/500，右侧组标题 15px/600，项目 15px/400；项目行高 52px，组间距 18px。
- 默认展开第一个存在可发布项目的组，否则展开该类首组。点击组标题只切换展开状态；同时最多展开一组。
- 已接入项目在组内优先显示，暂未开放项目保留明确标记和原有服务端准入检查。
- 切换大类使右栏回顶部；搜索全目录，并在关闭搜索后恢复原来的类别、分组及滚动位置。返回分类页保留原选中状态。
- 两栏均放在导航、标题下方的剩余空间独立滚动，移除旧的最小高度与视口减法造成的溢出和顶部遮挡。
- 保留发布页文字草稿箱入口、五个主 Tab；移除目录底部的主体审核说明，发布流程原有准入检查仍保留。

验证记录：

- `search-directory-regression.log`：211 项常规检查通过，0 失败；3 项 PostgreSQL 检查在常规命令中按原条件跳过。
- `search-directory-postgres.log`：另外启动隔离 PostgreSQL，55 项全部通过，无跳过；临时容器、网络、数据卷已清理。持久本地业务数据未清理。
- `search-directory-ui-result.json`：31 项微信开发者工具模拟器检查通过，0 失败，无捕获的运行异常。
- `check_project.py`：21 页面、5 Tab、26 个 WXML 的配置、事件处理和标签嵌套检查通过。
- 滚动/失败/延迟场景仅在自动化运行期间使用临时请求夹具，不写入后台；截图中的分类与空结果来自真实目录和本地 API。
- 未进行真机手势、软键盘和持续弱网验收，未部署线上环境。
