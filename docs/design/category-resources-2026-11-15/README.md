## 资源分包

图片与展示组件位于 `miniprogram/category-art/`。发布页及悼念页面使用微信小程序跨分包异步组件与 `componentPlaceholder` 接入。资源包下载期间，主包中的占位组件显示已有图标。

资源分包只有组件与素材，页面路由沿用已有28个页面。素材文件按 `category-art/assets/categories/行业ID/分类ID.webp` 命名，独立悼念入口素材位于同分包的 `assets/memorial/`。

本机未压缩资源分包约1.82MB，主包源码体积约2.08MB。精确源码字节见测试摘要。该测量覆盖本地文件及项目打包忽略项，微信正式编译上传包大小仍待取得。

微信预览上传尝试因开发者工具的代理 `127.0.0.1:10808` 连接被拒绝而失败。当前交付包含真实开发者工具渲染截图及本地回归结果。

跨包组件的配置方式可查阅微信分包异步化与占位组件说明。[微信开放文档](https://developers.weixin.qq.com/miniprogram/dev/framework/subpackages/async.html)

## 视觉待完善项

- 342张临时素材的专属3D替换仍待完成，原始映射已逐项标记。
- 76张初稿需要逐项核对裁切、语义、边缘和画布留白。抽查发现 `C01G01S01` 底部带有拼版文字残留，`C04G01S01` 左上角带有裁切边缘痕迹。
- 原有房屋插画也需要语义复核。`C05G01S02` 当前使用单椅场景，`C05G01S04` 当前使用沙发场景，后续定稿应替换为对应房屋场景。
- 部分素材使用实色背景，深色模式中仍会显示图片自身背景。后续定稿需要统一背景、主体比例和留白。
- Android与iPhone上的清晰度、弱网、滚动及真实下载耗时仍待真机验收。
- 微信预览上传与正式编译包大小仍待开发者工具网络恢复后验证。

## 后续替换

每个资源继续使用现有分类ID。替换对应WebP时同步更新素材状态及来源记录，并重新执行图片校验及页面检查。

`scripts/import_category_resources.py` 可校验并导入完整CSV与ZIP。脚本会检查分类ID唯一性、现有目录一致性、ZIP内外映射一致性及资源包体积。

```powershell
python scripts/import_category_resources.py --csv <映射表路径> --zip <资源包路径>
node --test backend/tests/category-resources.test.js
node scripts/check_category_resources_ui.js
```

完整来源映射见 [source-manifest.json](source-manifest.json)，插画制作清单见 [左右栏完整清单](../publish-3d-illustration-checklist-2026-11-15.md)。
