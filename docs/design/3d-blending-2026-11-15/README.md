# 发布页3D插画融合调整

## 本轮范围

以用户认可的房屋租售插画区域为风格基准，本轮完成默认数码闲置组的四张独立透明底3D图，并调整发布目录与搜索结果的图片融合方式。

| 分类 | 分类ID | 新素材 |
| --- | --- | --- |
| 二手手机 | C04G01S01 | [透明底3D手机](../../../miniprogram/category-art/assets/3d-v1/C04G01S01.webp) |
| 二手电脑 | C04G01S02 | [透明底3D笔记本](../../../miniprogram/category-art/assets/3d-v1/C04G01S02.webp) |
| 二手平板 | C04G01S03 | [透明底3D平板](../../../miniprogram/category-art/assets/3d-v1/C04G01S03.webp) |
| 二手数码配件 | C04G01S04 | [透明底3D耳机与充电盒](../../../miniprogram/category-art/assets/3d-v1/C04G01S04.webp) |

素材通过内置 imagegen 生成，采用珍珠白、浅粉、雾紫材质、立体倒角、柔和高光及落地阴影。四张发布素材为384×384 WebP，保留真实Alpha透明通道。生成提示词见 [prompts.md](prompts.md)，文件校验信息见 [assets.json](assets.json)。

## 页面调整

- 新3D图直接叠加在卡片图片区，主体与柔和底色自然衔接。
- 分类图片区采用与房屋租售接近的柔和渐变，扩大数码插画的展示高度。
- 浅色模式中，旧的实底初稿与临时图标使用视图层混合及柔边遮罩，弱化矩形画布边缘。
- 深色模式中，透明底3D图直接融入原有深色卡片，旧实底素材继续使用原图显示。
- 分类搜索复用同一批素材，图片失败时沿用原有图标回退。

本轮采用先完成默认四个数码分类的方式确定融合样式。其余342项临时素材的专属3D制作继续按原清单推进。

## 当前展示状态

原始资源包的76张初稿、342张临时图标及3张悼念入口图标继续作为来源记录留存。当前418项分类实际展示为4张本轮透明底3D图、72张原始3D初稿、337张临时图标和5张既有房屋插画。

新的四张图使用独立 `3d-v1` 路径，原始包文件及其SHA-256可继续核对。原始整合记录见 [分类资源接入基线](../category-resources-2026-11-15/README.md)。

## 复用与回退

`miniprogram/utils/category-art.js` 管理本轮四个分类的版本路径，`scripts/build_category_3d_assets.js` 将四张透明PNG整理为发布用WebP。

回退参考版本为 `13b43af`。回退本轮提交时一起恢复素材路径映射、卡片图片区样式、组件混合属性及对应验收代码。
