## 发布页插画

检查原有418项资源后，发现80组相同图像，共158项重复使用。现已重新制作163项透明底3D场景，覆盖全部重复项以及亲子母婴、宠物服务的全部26项。当前418份分类资源的图像内容哈希各不相同。

宠物诊疗、疫苗、洗护、美容、寄养、训练、摄影等项目分别使用医疗包、注射器、浴盆、剪刀、宠舍、训练用品与相机组合。亲子项目按游乐、摄影、生日、照护、洗护、托育、游泳和研学分别制作。美容护理使用泵瓶，运动使用水壶，母婴使用奶瓶。

本轮采用3dviz-pro-max的物体构造、材质与灯光指导，使用项目自建Blender几何模型和Cycles渲染。场景定义、生成器、导出脚本与逐项校验值均保存在项目中。

## 发现页筛选

城市、排序和筛选入口使用统一的浅灰粉工具栏。筛选按钮显示已选数量，普通状态展示可移除的条件标签，吸顶状态保留紧凑工具栏，完整条件在面板中管理。

筛选面板标题和底部操作固定，中间条件独立滚动。底部显示加载、已加载条数、空结果与失败重试，网络请求完成后可以查看结果。条数使用当前接口实际返回的数据，有下一页时明确显示“已加载”。

七个频道分别匹配用工与薪资、租售与面积、闲置价格与成色、商家距离、服务来源、活动时间和便民信息来源。房产先选租售目的，再选择对应租金或总价。删除发布目的会同步移除价格条件。重置后恢复“最新发布”。排序面板展示当前频道可用的方式。
