# 发布与草稿箱最终规则

更新：2026-10-20。本文替代此前可选草稿、嵌入式草稿箱和取消按钮的交互说明。本轮只调整发布流程与草稿管理，未重新设计全站配色，未扩大分类准入。

## 页面与操作

| 页面 | 实际结构 |
| --- | --- |
| 发布分类 | 发布内容；分类与项目、搜索、唯一草稿箱入口；保留五导航 |
| 发布填写 | 左上角返回、居中具体发布名称、分类路径和专用字段；底部仅“下一步 · 预览”；无取消或常驻保存按钮，无五导航 |
| 草稿箱 | 独立 `pages/drafts/index`；左上返回、居中草稿箱、无管理按钮；草稿卡片上方编辑，下方提示与删除；无五导航 |
| 预览 | 同一二级发布路由的只读预览状态；返回修改、确认提交审核；无五导航 |
| 提交成功 | 进入我的发布，管理审核中、已发布、已驳回和已下架内容 |

新建表单不读取旧草稿。未填写内容或未修改原稿，返回直接离开。存在未保存修改时，全流程只使用下面一套界面，不显示新建/编辑切换栏：

> **保存当前内容？**  
> 未保存的修改将在退出后丢失
>
> 保存并返回 / 不保存并返回 / 继续填写

新建主动保存创建独立本机草稿，回发布分类；草稿编辑保存更新原稿，回草稿箱。放弃修改保留原稿；继续填写保持编辑缓冲。保存失败显示“保存失败”，不退出、不清空。预览返回直接回当前表单，不出现退出询问。

输入、预览、页面隐藏和卸载不会自动生成或更新草稿。草稿入口仅位于发布分类页，个人中心保留我的发布、我的收藏、我的预约三项。原有账号草稿接口继续支持读取、更新与删除，不将新建本机草稿宣称为跨设备同步。

## 数据保留与并发

- 列表按最后保存时间倒序，显示标题或“未命名草稿”、分类、照片缩略图、时间，以及“本机保存”/“账号保存”。没有保存时间的历史记录明确显示时间未知。
- 未命名并不等于空草稿。兼容历史 `type`、`content`、照片及缺少提交编号的记录；可恢复的内容在主动保存时转入正常集合。读取不会直接改写原数据。
- 未知格式记录保持可见，暂不能恢复时明确说明，用户可以在卡片下方确认删除。写入其他草稿时保留未知原始字段和记录。
- 保存使用草稿修订号；历史记录额外校验原始内容指纹，防止旧页面覆盖新内容。迁移先完成集合写入，再处理旧单条记录；写入失败时保留原稿。
- 每张草稿卡片底部提供独立删除按钮，操作仍要求确认；本机删除校验修订和指纹，账号删除校验服务端修订。取消、冲突或失败不移除列表内容。
- 本机多条独立草稿互不覆盖；账号与本机的内容分别标明来源，不静默合并不同来源的内容。
- 提交在服务端重新校验分类、字段、图片归属与准入，使用提交标识防止重复创建。账号草稿提交携带读取时的版本，服务端在同一事务中校验；过期版本不能创建发布或删除新草稿。
- 提交成功仅清理对应源草稿；本机清理校验原修订。具有相同编号但内容不同的账号记录不会被本机副本顺带清空。提交失败保留表单与原稿。
- 预览与正式详情共用 `publication-display.js` 的金额单位、公开地区、分类路径和允许展示的属性规则。预览仍标明尚未发布。

## 主要代码位置

- `miniprogram/pages/drafts/`：独立草稿箱、卡片内删除、来源与时间、异步读取及账号隔离。
- `miniprogram/pages/publish/`：分类/搜索及唯一草稿入口；移除嵌入式草稿模式。
- `miniprogram/pages/publish-form/`：统一退出弹窗、返回目标、失败保留、账号草稿版本提交。
- `miniprogram/utils/local-drafts.js`：历史数据兼容、完整保存、并发校验和安全迁移。
- `miniprogram/utils/publication-display.js`、`presentation.js`、`pages/detail/`：共享预览与详情展示规则。
- `miniprogram/components/page-header/`：支持可选动作；草稿箱不设置右侧动作，保留居中标题与左侧返回。
- `backend/src/product-repository.js`：账号草稿提交版本校验和事务内条件清理；沿用既有数据库结构。

## 尚未验收与边界

上述微信证据来自开发者工具实际渲染、隔离测试账号及本机 PostgreSQL/API；自动化调用事件处理器，删除确认/取消通过模拟原生回调验证，不等同于手指操作、输入法、屏幕阅读器或真实双设备联动。

页面返回已按最终规则处理；微信系统返回和异常关闭的拦截能力受宿主限制，沿用未保存内容离开提醒，仍需真机检查手势返回、右上关闭及系统回收场景。未主动保存的内容异常关闭可能丢失，界面不宣称已保存。

未完成真机、持续弱网及读屏验收。418 项保持可搜索，现有 43 项发布映射保持开放范围，375 项仍受准入限制。本机草稿不提供跨设备恢复承诺；现有账号草稿仍为单条服务端能力，未扩成多条云同步系统。未进行生产部署或清空已有用户数据。

## 本轮界面简化

按最新参考图，发布分类页的入口仅保留“草稿箱”三个字，删除入口图标；草稿箱去掉管理/完成状态，卡片上方为缩略图或编辑线性图标、标题、摘要与右箭头，下方通过细分隔线划出“点击上方继续编辑”及带垃圾桶线性图标的删除按钮。沿用冻结的颜色变量和原有删除确认、修订校验、旧稿保留逻辑。

此次专项逻辑回归 24 项通过，微信模拟器界面与交互检查 22 项通过，覆盖纯文字入口、移除管理、卡片内删除确认、旧稿恢复及六种主题；记录见 `drafts-inline-client.log`、`drafts-inline-ui.log`。此前标为“管理模式”的截图属于历史版本，当前以 `drafts-inline-list.png`、`drafts-inline-cards.png` 和 `drafts-inline-ui-result.json` 为准。
