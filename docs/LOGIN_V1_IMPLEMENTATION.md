# 青方睐村美美 V1.0 登录实施记录

日期：2026-11-03。修改前审计、文件清单和验收条件见 [审计方案](LOGIN_V1_AUDIT_PLAN.md)。用户已说明暂不能配合真机，运营主体、隐私联系邮箱及测试域名稍后提供；当前继续完成可在本机验证的代码和流程。

## 已实现

- 保留原微信身份、服务端会话和手机号模块，新增极简登录页、共享登录组件及独立协议页，共26页，五导航和六主题保留。
- 游客可浏览首页、发现、分类、搜索及公开详情；受限请求经统一权限逻辑显示登录页。登录按钮需主动勾选当前协议；不自动取头像、昵称、手机号，不添加用户账号密码。
- 记录原路由、白名单参数及必要视图；页面仍在内存时恢复原操作。多个受限请求共用一次登录，取消不提交业务。换账号不重放旧账号表单或图片，退出后的迟到登录响应无效。
- 微信身份和手机号单独验证。服务端明确需要手机号时才进入验证页，说明用途、默认不公开，支持拒绝、取消和重试；没有虚构的短信或实名替代方式。
- 登录页复用顶部胶囊避让、安全区、PRISM GLASS、六主题及大字；只保留品牌、说明、登录、游客和协议。帮助入口也可阅读协议及打开微信隐私指引。
- 服务端用临时code交换openid，不返回AppSecret、session_key或微信服务access_token。独立随机会话令牌、数据库SHA256、7天有效期、有效账号检查、退出撤销及注销身份指纹沿用。
- 微信错误分为凭证失效、已使用、限流及服务异常，有限超时且不返回上游敏感URL。手机号服务凭证失效仅刷新重试一次；用户授权code失效仍需本人重新授权。
- 身份登录和号码交换分别按来源地址限制频率。多实例部署仍应在可信网关配置统一限流；不信任任意转发头。
- 029增加不可变协议同意和手机号授权事件，保存版本、文档摘要及号码修订号，不记录明文号码、临时code或session_key；换绑、解除验证、注销清理均留下审计。
- 个人数据导出包含本人协议同意和号码授权记录。绑定号码继续加密、掩码展示；公开电话须逐条单独同意，换号、撤回和注销关闭公开访问。
- 客户端默认关闭devLogin，正式服务端仍禁止开发登录；生产预检增加运营主体和隐私邮箱要求。缺少真实协议配置或微信配置时明确提示尚未就绪，保留游客浏览。
- 继续复用原发布、收藏、联系私信、商家、后台、积分、兑换和推广接口。行业资质撤销后不再结算对应贡献奖励，接受行业申请复用既有联系奖励采集，规则仍默认关闭。

全部测试覆盖已撤除，原鉴权存储比对一致；没有把隔离主体、测试号码、积分、商品或广告导入实际开发库。当前真实服务端仍缺微信凭据、运营主体和隐私邮箱，登录页会明确提示尚未就绪；公众浏览仍可使用。

## 待补的实际配置与验收

1. 在服务端填写真实`WECHAT_APPID`、`WECHAT_SECRET`、`PLATFORM_OPERATOR_NAME`、`PRIVACY_CONTACT_EMAIL`，密钥不写入小程序、文档或聊天。依法核对协议正文、实际保留期限和到期清理策略。
2. 将小程序接口改成实际HTTPS域名，在微信后台配置合法域名、实际服务类目及手机号权限。备案不自动提供这些能力。
3. 微信后台《用户隐私保护指引》须与实际收集范围、用途、运营主体及联系渠道一致；核对位置、主动头像上传及号码验证等实际使用能力。源码声明`__usePrivacyCheck__`和定位用途不能替代后台配置。
4. 分别在Android及iPhone验证：游客浏览；受限操作进入登录；协议未勾选；微信成功/失败/取消；成功后返回原收藏或发布；单独号码验证、拒绝和重试；换绑及解除后电话关闭；登录过期；退出；注销申请、审核执行后旧会话和原身份不可恢复。
5. 补测胶囊、安全区、六主题、大字、弱网、杀进程和返回栈满等场景。进程终止后不自动重发未保存的写入正文；返回原页面后由本人核对，已有草稿和有编号申请继续通过原恢复入口处理，避免重复提交。
