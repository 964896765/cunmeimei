## 改造前审计

已有微信登录、商家人工审核、内容待审、联系申请、基础屏蔽、内容举报和管理审计；未具备手机号验证、逐条电话公开授权、独立业务证明准入与申诉。聊天页仅使用本机演示记录，不能算作站内私信。

## 当前实际实现

仍只有微信小程序和原有 `/admin` 两个前端，共用一套 Node.js/PostgreSQL。新增登录/手机号/业务核验状态、分类准入、业务材料有效期与版本、风险记录、申诉及真实文字会话，未增加独立管理平台。

发布前验证手机号，商家/房源另外检查业务资格。正常微信用户新发布必须携带已开放的具体分类，不能省略分类 ID 绕过准入。418 项目录和 43 项原开放映射保持不变，未开放业务仍由服务端阻止。

人工只核验业务材料。房源分类发布资格与本条房源材料分开记录；本条材料绑定发布 ID 和内容修订版，不能自动继承到其他信息，内容修改后须重新核验。管理员也不能按旧版本审核通过已经修改的内容。

手机号默认不公开；逐条单独授权，绑定当前号码版本，撤销、换绑或解绑后对应公开设置失效。详情只在有效授权下提供电话；信息流不携带号码，公开文本中的号码按规则保护。图片仍需实际人工检查，不声称已有外部图片内容检测。

联系使用“申请 → 接受 → 站内文字会话”，支持结束、双方屏蔽、用户/消息举报。服务端校验归属、手机号、限频、屏蔽及会话状态；风险文字暂缓发送而不自动永久封禁。通知和列表摘要使用中性文案。

核验与运营角色使用独立服务端凭证。普通运营不能读取真实商家敏感材料或完成商家开通；普通用户不能读取他人核验、举报证据或私信。后台号码仅显示掩码，身份服务未接入时不存在可签发的身份认证。

## 运行与验收边界

当前本机手机号外部服务未配置，真实微信手机号授权和真机验收尚未完成；模拟器如实显示“微信授权手机号（未开通）”。合规身份服务和外部文字/图片安全检测也未接入。

本机开发身份仅用于隔离测试，API 仍支持开发环境的已有业务验收，但不生成手机或身份核验标识；生产环境禁止开发登录，该例外不能通过客户端参数开启。生产发布与联系还需实际确认平台主体/服务类目后配置相应开关，未确认时服务端拒绝相关操作。
