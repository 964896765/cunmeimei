## 首页轮播、广告与同城资讯

原先没有正式内容管理闭环的首页，增加持久内容、地区、排期、优先级、草稿、复核、停止展示与纠错处理：

1. 后台“首页轮播与同城资讯”保存草稿，资讯须有正文、原始来源名称及公开HTTPS来源。正文按纯文本显示，保留换行，不执行HTML。
2. 广告按城市搜索已审核公开信息，选择其图片和同一发布者的有效广告主体，预览原图；无需手填关联编号，保留高级编号入口以处理已有关联。
3. 业务核验角色确认广告主体和真实有效期；运营角色复核本条文字、原图、来源及广告证明后发布，二者权限分开，写入受CSRF与版本号保护。
4. 小程序展示有效排期的内容，广告明确标“广告”。广告主撤销、目标下架、图片不再属于目标、地区停止服务或排期到期，公开读取会再次过滤；前台到期清除并在点击前复查。
5. 编辑公开内容立即转回草稿，重新审核后才能展示。旧版本审核不能覆盖新稿。
6. 首页同城资讯进入正文、来源复制、纠错提交；纠错进入统一待办，处理答复通过站内通知回到本人记录，也可在本人数据导出中获得。

首页没有合规素材时显示平台使用指引和明确空态。本轮没有往持久开发库添加假资讯、广告主、商家或商品。广告是后台人工排期展示；自助付费、积分推广、定价和计费产品仍未开放。

后台入口：[本机运营后台](http://127.0.0.1:3101/admin)。使用已有服务端配置的后台角色与密码，凭据不写入本报告。

## 上线前仍须完成

本轮打通的是现有功能和人工运营内容链路，不能将其称为所有行业与所有商业产品均已开放。正式上线仍需要：

- 生产HTTPS与微信合法域名、正式登录/手机号授权与撤权、真实平台主体和对应经营类目核验。
- 真正可用且获授权的广告素材、广告主体资料和本地资讯来源；按实际供给发布，不填造假内容来消除空态。
- 对Android/iPhone进行真机、弱网、杀进程恢复、字体缩放、图片预览、导出与定位验收，并核对微信编译包体。
- 生产图片/材料安全流程、保留期限与定向删除、定时加密备份、私有文件/密钥恢复及告警实测。
- 375个未开放项目逐项补业务模板及资质流程；贡献规则的正式运营审核，积分兑换、广告自助申请/计费和微信订阅提醒另行完成产品设计与验收。当前保持关闭。
