# 积分兑换、自助推广与375项业务流程

日期：2026-11-03（Asia/Shanghai）。本轮继续原项目，新增027、028迁移，保留五导航、六主题及43项居民发布表单。现有24页，新增“权益与推广”“行业业务工作台”。未连接、部署或迁移生产环境。

## 用户入口

- 我的 → 积分兑换与自助推广；积分明细页也可进入。分为积分兑换、本人兑换记录、自助推广三个工作区。
- 发布目录 → 各行业项目 → 对应居民表单、行业业务表单或来源线索表单。机构主体先申请本项目核验，个人可先明确保存草稿。
- 我的 → 行业业务、申请与核验记录。分为我的业务、我的申请、收到的申请、主体核验、举报答复。
- 发现 / 搜索 / 收藏 → 已审核行业信息 → 公开行业详情，按业务类型申请、免费报名、咨询或核对来源。接受申请后可进入已同意的站内文字会话。
- 消息 → 积分 / 审核通知 → 本人对应兑换、推广或行业业务记录。旧记录可以按本人权限定位，其他账号无法读取。
- [本机运营后台](http://127.0.0.1:3101/admin) → 统一待办，或展开“积分权益、自助推广与行业业务”。主体资料及专项资质由业务核验角色处理；权益、内容、广告素材和举报由运营角色处理。

## 积分兑换

后台可创建、修改、开放和暂停实际权益，设置积分价格、剩余可兑换库存、交付内容、领取条件及售后规则。没有预置虚构礼品或未经确认的外部优惠券。

用户确认价格和规则后，服务端锁定库存、保存权益快照并冻结准确积分；库存与冻结在同一事务提交。剩余库存与版本变化会要求重新读取，不能透支或超兑。申请编号绑定原内容，重试不会重复扣分或领取另一份权益。

核销前用户可取消；后台可拒绝；72小时未核销自动到期。三种情况均退回原冻结积分并恢复一份库存，重复操作不会再次退还。后台只有确认实际交付、填写本人可见核销凭据后才消费原冻结积分；交付记录、积分账本及审计保留，不通过直接改余额处理差错。

本人可查快照、状态、期限、处理说明及核销凭据；其他用户无法读取。修改权益配置不会改写已提交订单的原价或规则。需要后续售后复核时，凭原订单记录和账本走现有帮助/人工核查流程；没有提供绕过实际交付的自动现金退款或积分提现。

## 自助推广

1. 用户提交真实广告主体名称与不含个人号码的材料工单引用，由独立业务核验角色确认材料、适用范围及真实有效期。
2. 用户选择本人已公开信息、该信息已审核图片及有效广告主体，提交本条推广标题。此时不扣积分。
3. 运营逐项检查本条文字、原图、使用权、业务广告规则与证明，审核通过后，用户再选择城市/地区排期并最终确认积分价格。
4. 服务端重新检查账号、平台发布批准、号码与风险限制、主体、图片归属、目标有效期、城市、库存、版本和价格。库存确认与原冻结积分消费一起提交，重试只返回原排期。
5. 生效时展示在首页轮播，明确标“广告”。排期到期、停投、目标下架、主体或行业资格失效后，公开读取会重新过滤。首页保留到期清除、前台刷新及点击前复查。
6. 开始前可取消，按原消费全额冲正并释放库存；开始后可以停止展示或恢复原排期，不自动退分。已开始的退款争议保留记录，交运营核查实际停投与交付范围。

后台可配置排期、查看剩余位置及关闭/恢复新预订；关闭新预订保留已确认投放的库存和权益。人工轮播与自助排期共同核对重叠位置，上限5个，关闭预订但已有投放的时段也计算占用，避免新排期挤掉原投放。

普通已核验商家、服务、房源、招聘、免费活动和互助信息可按规则提交通用推广。官方指引、编辑线索、医疗/金融等持牌目录与专项许可服务不因普通广告主体核验就获得广告准入，未实现其专门广告许可产品。推广不承诺浏览量，不按浏览或广告点击发积分，不提供充值、现金支付、提现或转让。

## 数据、权限与异常恢复

- 本项目资质范围精确绑定项目ID，不用一个通用“已核验”解锁全部375项。撤销或过期时，公开详情、发现列表、图片及推广重新检查可见性。
- 免费活动名额包括待处理与已接受申请，事务锁防止争抢超额；撤回、拒绝、结束或修改原业务后释放名额并保留历史。业务内容修改撤回展示并重新审核，原申请和已建立会话同步结束，避免新条款覆盖旧约定。
- 申请说明和答复仅双方可读，接受后建立已同意的站内会话；退出、结束及资格失效限制继续发送。关闭接收新申请或存在屏蔽记录时不能借行业申请绕过限制。不收简历附件、证件号或公开手机号。
- 前台发送前保存按账号隔离的请求编号和原请求，弱网结果不明时先核对同一请求；明确拒绝与不确定结果区分处理。切换账号、页面失效或迟到响应不能写入其他账号界面。
- 本人导出增加兑换、推广、行业业务、申请、资质及举报，共20个数据分区。注销前检查未完成申请、冻结积分和推广义务，保留必要账本与审核证据。
- 后台统一待办包括权益核销、推广素材、广告主体、行业内容、行业资质与举报。写入受角色、CSRF、状态和修订号保护；不在只读接口完成审批。
- 维护任务增加兑换到期释放及行业到期结束；既有账本核对、广告到期、贡献结算与异常待办继续运行。
